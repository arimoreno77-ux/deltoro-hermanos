# Guía de Estilo Visual (Inspiración ATEEVIBES / Urban Collage)

## 1. Estética General
- **Estilo:** Urban Streetwear / Collage Editorial / Neo-Brutalismo.
- **Elementos clave:** Texturas de papel rasgado, efectos de medio tono (halftone), detalles tipo grafiti y pinceladas rojas de alto impacto.
- **Atmósfera:** Urbana, cruda y de alto contraste.

## 2. Tipografía
- **Titulares:** Tipografía Sans-Serif en mayúsculas (Condensed/Bold, impacto visual fuerte).
- **Cuerpo:** Sans-Serif limpia (Inter / Helvetica) para mantener legibilidad.

## 3. Paleta de Colores
- **Fondo:** Crema / Papel crudo (`#F4F1EA` aprox) o Modo Oscuro de alto contraste.
- **Texto Principal:** Negro absoluto (`#000000`).
- **Acento:** Rojo vibrante / Graffitero (`#E61C1C` aprox).

## 4. Layout y UI
- Composiciones superpuestas (capas, fotos cortadas, cinta adhesiva/papel roto).
- Tipografía gigante en el Hero con navegación minimalista arriba.
- Botones sólidos de esquina recta y contraste extremo.
